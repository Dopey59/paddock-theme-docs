Support

What support covers

  • Bug fixes: if something in Paddock doesn't work as described in this documentation, we fix it in the next update.
  • Questions about the theme's features, sections and settings.

Support doesn't cover custom code, changes to the theme files, or third-party apps. For those, we recommend hiring a Shopify Partner. Always duplicate your theme before editing its code.

We answer within two business days, Monday to Friday.

Before you write

  1. Read the FAQ: most questions are answered there.
  2. For fitment problems, follow the checks at the end of the setup guide.

Contact us

Your request opens as a support ticket on GitHub (a free account is needed). GitHub emails you when we reply. Tickets are public: never include passwords, API keys or customer data.
