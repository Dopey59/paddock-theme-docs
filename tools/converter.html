Paddock fitment converter

Turn your fitment sheet (one row per product and vehicle) into files you can import into Shopify. Everything happens in this browser window: your files never leave your computer, and this page works offline.

1Your fitment sheet (required)

CSV file with the columns product_handle or sku, make, model, year_from, year_to, engine. Excel: File → Save as → CSV.

2Your Shopify product export (optional)

Shopify admin → Products → Export → "All products", "CSV for Excel, Numbers…". Needed only if your sheet uses SKUs instead of handles, or if you want the "tags" file (no app needed). It is also used to check that every handle exists.
